# Детектив — بازی کارآگاهی مسکو

وب‌اپ آموزش افعال حرکتی روسی در قالب بازی کارآگاهی.

## نسخه آنلاین

بعد از پوش روی `main`، GitHub Pages بازی را از پوشه `dist` منتشر می‌کند:

`https://<username>.github.io/detektiv/`

## اجرا (محلی)

```bash
npm install
npm run dev
```

مرورگر: http://localhost:5173

## ساختار پروژه

```
src/
├── types/game.ts          # تایپ‌های مشترک (مکان، NPC، سناریو، ...)
├── data/
│   ├── locations.ts       # ۹ مکان ثابت + نقاط نقشه
│   └── scenarios/
│       └── scenario1.ts   # سناریو ۱: تابلوی گم‌شده
├── hooks/useGame.ts       # منطق بازی (تایمر، هینت، دیالوگ، ...)
├── components/            # UI
└── assets/placeholders.ts # پس‌زمینه‌های موقت
docs/
└── IMAGE_PROMPTS.md       # پرامپت تولید تصاویر
```

## گیم‌پلی

1. **صفحه عنوان** → شروع پرونده
2. **قواعد** (صوتی با Web Speech API) → فهمیدم / هینت (+۱۰ث)
3. **اتاق کارآگاه (Hub)** — دید اول‌شخص
4. **ابزارها**: نقشه | کوله‌پشتی | دفترچه
5. **مکان‌ها** → دیالوگ با NPC → سرنخ + افعال حرکتی در دفترچه
6. **حل معما** — انتخاب مجرم
7. **برنده**: کمترین زمان (با جریمه هینت)

## افزودن سناریوی جدید

1. فایل جدید در `src/data/scenarios/`
2. `locationOrder` ترتیب باز شدن مکان‌ها را تعیین می‌کند
3. دیالوگ‌ها `motionVerbs` دارند — خودکار در دفترچه ثبت می‌شوند
4. مکان‌ها و ابزارها مشترک می‌مانند

## تصاویر

پرامپت‌ها در `docs/IMAGE_PROMPTS.md`. پس از تولید، در `public/images/` قرار دهید.

## مدل آنلاین (پاسخ کوتاه)

**بله، این مدل آنالوگ آنلاین دارد:**

| بازی مشابه | شباهت |
|-----------|--------|
| **Sherlock Holmes Consulting Detective** | کارآگاهی، نقشه، جمع سرنخ، حل معما |
| **Detective: A Modern Crime Board Game (digital)** | بازجویی NPC، تایمر، سرنخ |
| **LA Noire / Disco Elysium** | دیالوگ، کارآگاهی (البته AAA) |
| **Duolingo Stories / Babbel** | آموزش زبان در قالب داستان |

تمایز این پروژه: **آموزش ضمنی افعال حرکتی روسی** + **مکان‌های ثابت مسکو** + **چند سناریو روی یک موتور مشترک**.

برای آنلاین واقعی بعداً می‌توان: لیدربورد زمان، حالت چندنفره race، یا co-op اضافه کرد.
